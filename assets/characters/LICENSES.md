# Bundled character assets and original terms

Source repository: https://github.com/madjin/vrm-samples
Pinned source commit: e16eb187100149a315ad92c3c9968f1d5baa6c7d

These are third-party character assets, not Yumi-authored artwork. Models are
copied byte-for-byte. Original metadata, authors, permissions, source links and
SHA-256 hashes are recorded per model in `manifest.json`. Integration changes
only how Yumi selects and animates the humanoid rig, not the original asset.
Yumi's code license does not replace these asset terms.

VRoid sample conditions and original creator references:
- https://vroid.pixiv.help/hc/en-us/articles/4402614652569
- https://vroid.pixiv.help/hc/en-us/articles/4402394424089

AvatarSample A/B/C are subject to the pixiv sample model terms, not CC0.
This local bundle is for the user's existing Yumi installation; do not relabel
the assets or sell the sample files independently.
